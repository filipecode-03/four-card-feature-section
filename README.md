# 🧩 Four Card Feature Section – Frontend Mentor Challenge

### 📌 About the Project

This project consists of a **featured section composed of four cards**, developed from a challenge on the **Frontend Mentor** platform.
The objective was to reproduce the proposed layout using exclusively **HTML and CSS**, focusing on semantic structuring, visual organization, and fidelity to the original design.
The project reinforces essential front-end development fundamentals without the use of JavaScript.

### 🛠️ Technologies Used

[![My Skills](https://skillicons.dev/icons?i=html,tailwind)](https://skillicons.dev)

### 🧠 Learnings

During the development of this project, it was possible to:

- Practice creating sections composed of multiple cards.
- Improve **layout skills with CSS Grid and/or Flexbox**.
- Work with visual hierarchy, colors, and typography.
- Emphasize attention to visual details as per the challenge design.
